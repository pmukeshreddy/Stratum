# Prime refinement test-to-port map

The supplied Prime source/tests are authoritative. Counts are **test definitions**, not expanded parameter cases. Each candidate retains its source file, exact name, implementation, Buffalo counterpart, test, and disposition.

**317 candidates: 235 applicable; 235 mapped; 235 passing; 0 unmapped applicable; 0 known scoped behavioral deviations.** The other 82 rows explain structural or out-of-scope exclusions individually. Ten formerly open candidates were classified as structural exclusions after checking their specific APIs (P015, P025, P083, P095, P111, P113, P135, P146, P182, P213); they were not counted as implemented. Supported input, abort, disposal and context-delivery paths have direct regressions.

The scope is the self-reinforcement loop on Buffalo's existing session and provider surfaces, not all of Prime's ACP/TUI/extension/standalone-Python APIs. Generic compaction continuation, RLM, verification, benchmark scoring and unsupported provider APIs remain outside this port. Refinement's compaction trigger, context delivery, cooldown and branch invalidation are included.

Prime test paths are relative to `packages/coding-agent`; `../../prime-agent-runtime` names the sibling Python package. Prime implementing `core/` paths are under `packages/coding-agent/src`. Buffalo production paths are under `src/threadweave`.

source checkout.
