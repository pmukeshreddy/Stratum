# Runtime and refinement source review

This is the initial-pass audit. The [focused second-pass audit](refinement-review-history.md) supersedes its conclusions about manual refinement, compaction review checkpoints, auxiliary graph membership, and refinement state visibility.

This review compares executable paths, not README descriptions. The reference is the September 7, 2026 source in the archived source ZIP (SHA-256 `18edd31aa8bf1bb2765953328c4cffbab56fa56f2783027b2ee80d5d30fc2a86`), extracted at the external reference checkout.

No remaining weaker behavior was found within the requested runtime contracts. These classifications concern the paths above, not a claim that the entire Buffalo product exceeds the reference.

## Buffalo mechanisms retained

Coding children retain repository intelligence, evidence/verifier policy, test protections and resource accounting. Shared children reuse the parent's original coding baseline, so a parent's existing edits do not become a new baseline or make shared admission fail as dirty. Candidate/test/performance specializations retain isolated worktrees; contradictory requests for shared candidates fail explicitly. Research/review specializations retain coding capabilities with their explicit read-only policy.

The event store, action recovery journal, permission checks, provenance, test-selection infrastructure, versioned memories/prompt notes/skills/subagent specifications and retrieval remain in the production path. Forking remains a new Buffalo session with copied state rather than an in-place branch switch.

## Validation and limits

- Final Python suite: **415 passed, 9 skipped, 2 warnings in 85.05 seconds**, using `.venv/bin/python -m pytest -q`.
- **32 added behavioral cases** in `tests/test_runtime_contracts.py`; existing tests retain their assertions except where the requested contract changed (shared coding specialization and periodic semantic review) or mocks/accounting needed the additional reviewer call. The existing interrupt test now waits for a post-mutation stdout marker instead of file creation, removing a synchronization race while preserving its assertions.
- Ruff and `git diff --check` pass. The two full-suite warnings concern Python's `forkpty()` deprecation in the existing terminal integration test.
- The native bridge passes `cargo check` and its executable unit test against Buffalo's pinned Codex source, revision `3d2ee51ca2d5db578f328aa75e20aa22c0197c9a`.
- Model behavior is verified with controlled providers and a mocked HTTP transport. No live paid-provider inference was performed for this change; the nine skipped tests remain skipped.
- Schema 11 preserves existing context/compaction/state data. Request IDs apply to invocations after upgrade; historical wire identities are not invented. Legacy queued updates with no provable baseline conflict safely instead of assuming freshness.
- Unknown provider billing remains explicitly estimated/unknown. Request attribution preserves that uncertainty rather than presenting estimated spend as exact reported billing.

Inspect runtime request relationships with `Store.request_graph(session_id)` and per-request/delegated usage with `Store.request_usage(request_id, delegated=True)`.
